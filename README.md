# 滴答 Dida 🏷️→👁️

macOS 菜单栏常驻的眼药水 & 护眼提醒。为过敏性结膜炎 + 干眼症设计：
每天三次「富马（抗过敏）→ 间隔 5 分钟 → 聚乙二醇（人工泪液）」的两步用药流程，
加上 20-20-20 护眼休息提醒。原生 Swift，无 Dock 图标，无主窗口，
1Hz 单计时器 + 事件驱动，常驻开销约等于零。

## 功能

- **两步用药提醒**：到点弹出置顶确认窗（不抢键盘焦点，必须点「已滴完」或「稍后 5 分钟」），
  滴完富马 → 间隔 → 弹聚乙二醇确认 → 本轮完成。两步分色：富马=珊瑚，聚乙二醇=青。
- **护眼休息提醒**：默认每 20 分钟弹轻量横幅「看远处 20 秒」，20 秒自动消失，可点击提前关掉。
- **主动休息**：`⌥⌘B` 一键开始/结束休息（默认 5 分钟自动回来）。休息是你的，应用只记账不评判——
  提前结束会报告实际休息时长（"闭眼眨眼也有效"），面板里可「再休 5 分钟」。
- **会议静音**：`⌥⌘M` 一键静音所有提醒，默认 60 分钟自动恢复，不怕忘。静音时菜单栏图标变 `eye.slash`。
- **可配置**：用药时间点（默认 11:00 / 15:00 / 20:00，可增删 1–6 个）、两药间隔、护眼间隔（5–60 分）、
  休息时长（1–30 分）、静音时长（5–240 分）、药名、提醒音效——全部适配不同作息与不同人。
- **错过宽限**：睡眠唤醒后 30 分钟内错过的用药提醒立即补弹，超过则静默顺延。
- **真·毛玻璃**：NSVisualEffectView behindWindow 实时模糊，深浅色外观自适应，「晨露」配色
  （深青 = 健康行动，天蓝 = 休息，琥珀 = 静音）。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `⌥⌘M` | 静音 / 恢复提醒（会议模式） |
| `⌥⌘B` | 开始休息 / 提前回来 |

## 构建与运行

需要 Xcode Command Line Tools（`xcode-select --install`）。

```bash
./scripts/build.sh
open dist/Dida.app
```

## 登录自启动

在面板「设置」里打开「登录时启动」即可（通过 LaunchAgent 实现，无需签名）。

## 设计

- 设计方法与质量底线来自 [impeccable](https://github.com/pbakaus/impeccable)，
  产品上下文见 [PRODUCT.md](PRODUCT.md)。
- 休息间隔依据 20-20-20 法则（2023 年临床研究证实对数字视疲劳/干眼有效）；
  两药间隔 5–10 分钟为医嘱惯例；眼药水开封后 4 周应更换。
- 用药与休息的交互原则：**坚持但不纠缠**——用药必须确认但绝不抢键盘焦点；
  休息只记账不评判；静音永远一键可达且总会自动恢复。

## 卸载

1. 面板「设置」关闭「登录时启动」（或删除 `~/Library/LaunchAgents/com.blueDaydreaming725.dida.plist`）。
2. 面板右下角「退出滴答」，删除 `dist/Dida.app`。
